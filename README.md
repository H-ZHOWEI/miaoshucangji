# 喵数仓记

一个 Windows 桌面**仓库 / IT 资产管理工具**：登记物品、做出入库、给每次领用留凭证图片、随时查历史记录。

基于 Python + tkinter 开发，用 PyInstaller 打包为单文件 `喵数仓记.exe`，免安装、双击即用。数据全部存本地 CSV，不需要数据库、不联网。

## 主要功能

- **库存总览**：按物品名称汇总成一行，直接看当前库存、最近操作日期、是否需补货
- **新增物品**：登记编码、名称、规格、数量、申请公司、类别（月度 / 非月度采购）、购买链接
- **入库**：选公司和物品，填数量，库存自动累加，同时留一条入库记录
- **出库**：填领取部门、领取人、领取时间，**必须上传领料单图片**，库存自动扣减并校验不足
- **操作记录**：分「全部 / 新增 / 变更删除 / 入库」四个标签页，每行可看有没有图片凭证
- **物品明细**：双击库存行，看这个名称下所有规格条目的编码、公司、类别、库存、购买链接
- **购买链接**：明细里一键复制，方便补货时直接下单
- **实时搜索**：搜索框输入即过滤，不用按回车

## 快速开始

1. 双击 `喵数仓记.exe`
2. 点右上角 **「新增物品」**，填编码、名称、规格、数量，选物品类别，保存
3. 以后进货点 **「入库」**，领用点 **「出库」**
4. 想查历史点 **「操作记录」**

详细步骤见 [操作说明.md](操作说明.md)。

## 三张统计卡片的口径

这三个数字算法不同，容易看错，这里写清楚：

| 卡片 | 算法 |
|---|---|
| 库存物品总数 | 按「名称 + 规格」去重后的组合数（同一物品不同规格算两条） |
| 库存总量 | 所有条目 `quantity` 直接相加 |
| 低库存物品 | **所有** `quantity < 2` 的条目数（不分类别，也不去重） |

## 「状态」怎么判定

表格里的状态是按**物品名称分组**后算的，规则只有一条：

> 组内只要有一条 **「月度采购物品」且库存 < 2**，整组显示 **需补货**（红字）；否则一律显示 **库存充足**。

所以「非月度采购物品」即使库存为 0，状态仍然是「库存充足」——这是设计如此，不是 bug。非月度物品通常按需采购，低库存不代表要补。

## 新增物品时的合并规则

新增时如果已存在**名称相同 + 规格相同 + 申请公司相同**的条目，程序不会新建一行，而是：

- 把数量**累加**到已有条目
- 更新「最近操作日期」为你填的新增时间
- 只在原来的类别 / 购买链接为空时才补上

这意味着一件事：**想记录同一物品的两次不同采购价或不同来源，得靠「申请公司」或「规格」区分开**，否则会被合并。

## 操作记录里的类型

| 界面显示 | 对应动作 |
|---|---|
| 新增 | 「新增物品」提交 |
| 入库 | 「入库」提交 |
| **变更** | 「出库」提交，以及编辑 / 删除物品明细 |
| 删除 | 删除物品明细 |

注意 **出库没有独立的标签页**，它的记录类型和「编辑、删除」一样，都归在 **「变更/删除记录」** 页里，显示为「变更」。想看某次领用，去那一页找，或者直接在「全部记录」里按日期翻。

## 数据存放

两个 CSV + 一个图片目录，**都相对于启动程序时的工作目录**：

| 路径 | 内容 |
|---|---|
| `inventory.csv` | 当前库存（每个物品每个规格一行） |
| `records.csv` | 所有操作流水 |
| `record_images/YYYYMM/` | 出库时上传的领料单图片，按月分文件夹 |

`inventory.csv` 字段：

```
id, code, name, spec, quantity, company, last_updated, category, purchase_link
```

`records.csv` 字段：

```
id, type, item_id, code, name, spec, quantity, company, department,
recipient, date, operation_date, notes, image_path
```

其中 `type` 取值 `add` / `restock` / `update` / `delete`，`image_path` 是相对路径（如 `record_images\202601\xxx.jpg`）。

仓库里附了两份示例：[inventory.example.csv](inventory.example.csv)、[records.example.csv](records.example.csv)，只有格式，不含任何真实数据。

> **备份就是复制这三个东西**：`inventory.csv`、`records.csv`、`record_images/`。三者要一起拷，否则记录里的图片路径会指向不存在的位置。

## 从源码运行

```bash
pip install pillow
python reminder_app.py
```

只需要标准库 tkinter + Pillow（处理图片）。

## 自己打包

双击 `package.bat`，或执行：

```bash
pyinstaller --onefile --windowed --noconsole --name "喵数仓记" --icon=application-note.ico reminder_app.py
```

产物在 `dist/喵数仓记.exe`，约 27MB。

## 常见问题

**打开后表格是空的？**
程序按**启动时的工作目录**找 `inventory.csv`。如果你用快捷方式启动、且快捷方式的「起始位置」是空的，就会读不到数据。解决办法：从 exe 所在文件夹双击启动，或者右键快捷方式 → 属性 → 把「起始位置」设成 exe 所在目录。

**CSV 用 Excel 打开中文乱码？**
程序写的是 UTF-8 无 BOM 的 CSV，Excel 双击时会按本地编码解析导致乱码。用 Excel 的「数据 → 从文本/CSV」导入并选 UTF-8，或用记事本 / VS Code 打开。**不要在 Excel 里改完直接保存**，Excel 会改列格式和编码，程序可能读不了。

**出库提示「库存不足」？**
程序按所选物品条目的 `quantity` 判断，不够就拒绝。先核对是不是选错了规格或公司。

**图片传不上去？**
限制 jpg / jpeg / png / bmp，单张 5MB 以内；超过会提示「图片文件太大」。

**删了物品明细，库存没变回来？**
删除明细是直接删条目，不会生成反向流水。如果是误删，从 `records.csv` 里找回来手工补。

**会不会上传我的数据？**
不会。程序只读写本地 CSV 和图片目录，没有任何联网行为。仓库里也不含任何真实台账数据。
